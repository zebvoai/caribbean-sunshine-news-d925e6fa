# Dominica News

A modern news platform for the Commonwealth of Dominica — breaking news, politics, business, sports, and Caribbean coverage.

## Tech Stack

- Vite
- TypeScript
- React
- shadcn-ui
- Tailwind CSS

## Local Development

Requires Node.js & npm — [install with nvm](https://github.com/nvm-sh/nvm#installing-and-updating).

```sh
# Clone the repository
git clone <YOUR_GIT_URL>

# Enter the project
cd <YOUR_PROJECT_NAME>

# Install dependencies
npm i

# Start the dev server
npm run dev
```
